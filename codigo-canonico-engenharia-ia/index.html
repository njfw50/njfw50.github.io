Código Canônico de Engenharia & IA

Um protocolo para organizar o trabalho entre engenheiros e assistentes de IA, com decisões que podem ser examinadas e explicadas.

Da geração de código à responsabilidade sobre o sistema.

O Código Canônico de Engenharia & IA é um projeto de Michel Silva de Souza, publicado também como The Canonical Protocol of Engineering & AI. Seu corpo documental reúne governança de software, arquitetura, segurança, experiência do usuário e o trabalho com assistentes de IA.

O projeto apresenta a Anotação Cognitiva Litúrgica (Liturgical Cognitive Annotation) e discute dívida cognitiva: a perda de compreensão do sistema durante o desenvolvimento assistido por IA. Os textos originais, as propostas e o histórico estão disponíveis no repositório público.

Uma situação para examinar com o Código

Imagine uma revisão de código em que um assistente de IA colocou uma regra de desconto diretamente na interface de checkout. O ponto de partida para a discussão é o texto do Canon X:

Layers must not harbor improper dependencies. Specifically, the Domain layer must remain pure and entirely oblivious to Infrastructure or Interface concerns. Dependencies must always point inwards.
Canon X · Article 10.2

Onde está definida a regra de desconto? Quais componentes dependem dela? Que decisão e evidência a revisão precisa registrar? Este é um exemplo didático para orientar a leitura do texto integral.

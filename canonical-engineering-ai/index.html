From generating code to understanding the system.

The Canonical Protocol of Engineering & AI is a project by Michel Silva de Souza, also known as Código Canônico de Engenharia & IA. Its documents address software governance, architecture, security, user experience and work involving AI assistants.

The project introduces Liturgical Cognitive Annotation and discusses cognitive debt: the loss of understanding of a system during AI-assisted development. The original texts, proposals and history are available in its public repository.

This is a governance framework for AI-assisted software engineering. It proposes traceable decisions, architectural review and explicit code provenance. Its application depends on the context and evidence of each project.

A situation to examine with the Code

Imagine a code review in which an AI assistant has placed a discount rule directly in a checkout interface. The starting point for discussion is the text of Canon X:

Layers must not harbor improper dependencies. Specifically, the Domain layer must remain pure and entirely oblivious to Infrastructure or Interface concerns. Dependencies must always point inwards.
Canon X · Article 10.2

Where is the discount rule defined? Which components depend on it? What decision and evidence should the review record? This is an educational example to guide reading of the complete text.

How can you use the protocol?

Who is it for?

Engineers, students and teams using coding assistants who want to examine architecture, cognitive debt and responsibility for generated code.

Where should you start?

Run the checkout above and trace a decision from domain policy to interface. Read the worked decision record, then apply the questions to one small change in your own project.

What is automated today?

The example checks its fictional policy. The repository also contains configuration files and demonstrative checks. A real system needs implemented controls and review; the protocol does not automatically certify all code.

What has been demonstrated?

The example illustrates separated layers and boundary checks. The method’s effect on cognitive debt still requires evaluation. Read the sources and evidence limits.
